The daily runner writes one file here per request (`<request id>.yaml`): the measured numbers, `outcome`
(`confirmed`, `refuted` or `inconclusive`), the model commit and the date. Each file arrives in its own
results PR (`Results <request id>: <outcome>`), linked from a comment on the request's PR. Don't add files
here by hand. See [EXPERIMENTS.md](../EXPERIMENTS.md#results).
